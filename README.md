# Selenium tests for Yandex Samokat

Автотесты для учебного сервиса «Яндекс.Самокат».
Реализован по паттерну Page Object, с параметризацией тестов и отчётом в Allure.

## Технологии
- PythonS
- Selenium
- PyTest
- Allure
- Page Object Model

## Установка
```
pip install -r requirements.txt
```

## Запуск тестов
```
pytest tests/ -v
```
